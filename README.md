# Synthetic Wearable Physiological Signals and Stress Labels for Four Training Scenarios

Dataset accompanying the article:

> Huang, S.-F., Huang, Y.-P., & Hu, H.-C. (in review). *Predicting Psychological Stress in Training Scenarios from Wearable Physiological Signals with an LSTM Model: A Simulation-Based Feasibility Study.*

## Overview

All data in this dataset are **synthetic**. They were generated by a rule-based simulator; no human participants were involved and no real personal data are included.

Four scenarios cross task intensity with psychological stress:

| Scenario | Task intensity | Psychological stress | Mean stress index |
|---|---|---|---|
| S1 | Low | Low | 17.8 |
| S2 | Low | High | 59.4 |
| S3 | High | Low | 42.8 |
| S4 | High | High | 78.4 |

Each scenario contains 2,000 one-second records (stages 1–2) or 1,999 records (stage 3). Stage 3 contains 7,996 records in total.

## Generation pipeline and folder structure

The data were produced in three sequential steps. Each folder holds the output of one step.

| Step | Folder | Content |
|---|---|---|
| 1 | `1_raw_signals/` | Simulated wearable signals per scenario: heart rate, SpO2, step count, and RR interval |
| 2 | `2_hrv_windows/` | Heart rate variability computed from the step-1 RR intervals with a trailing 180-second window |
| 3 | `3_model_dataset/` | Model-ready dataset: step-1 signals, step-2 SDNN, the stress label (0–100), and the simulated electrodermal (ESA) channel. **This is the dataset used for all model training and evaluation in the article.** |

Row alignment: row *k* of a stage-3 file corresponds to row *k + 1* of the matching stage-1 and stage-2 files, because the first record (for which no HRV can be computed) was dropped.

## Data dictionary

### Stage 1 — `*_raw.csv`

| Column | Unit | Description |
|---|---|---|
| `timestamp` | ISO 8601 | Simulated time stamp (1 s resolution) |
| `index` | – | Record index within the scenario (0–1999) |
| `hr_bpm` | beats/min | Simulated heart rate (PPG-type signal) |
| `SpO2_pct` | % | Simulated blood oxygen saturation |
| `Step` | count | Simulated step-count activity value per record |
| `RR_ms` | ms | RR interval derived from heart rate (60000 / HR) |

### Stage 2 — `*_hrv.csv`

| Column | Unit | Description |
|---|---|---|
| `window_start`, `window_end` | ISO 8601 | Start and end of the trailing HRV window (up to 180 s) |
| `nn_count` | – | Number of NN intervals in the window |
| `avnn` | ms | Mean NN interval |
| `sdnn` | ms | Standard deviation of NN intervals (SDNN) |
| `rmssd` | ms | Root mean square of successive differences |
| `pnn50` | proportion | Proportion of successive differences > 50 ms |
| `hr_mean` | beats/min | Mean heart rate in the window |
| `artifact_rate` | proportion | Proportion of intervals flagged as artifacts |
| `status` | – | `OK`, or `NOT_ENOUGH_DATA` while the window is still filling |

### Stage 3 — `*_model.csv`

| Column | Unit | Description |
|---|---|---|
| `hr_bpm` | beats/min | Heart rate (from stage 1) |
| `SpO2_pct` | % | SpO2 (from stage 1) |
| `Step` | count | Step-count activity value (from stage 1) |
| `sdnn` | ms | SDNN (from stage 2) |
| `stress_psych_0_100` | index (0–100) | Stress label: scenario-level load from a NASA-TLX-informed rubric plus a record-level random component |
| `eda_uS` | µS | Simulated electrodermal-type sympathetic activation channel, referred to as ESA in the article |

Model inputs in the article: `hr_bpm`, `SpO2_pct`, `Step`, `sdnn`, `eda_uS`. Target: `stress_psych_0_100`.

## Notes and limitations

- The data are synthetic and encode predefined physiological–stress relationships. Results obtained on them are an upper-bound feasibility benchmark, not evidence of real-world validity.
- Records are generated independently over time; the series do not reproduce the temporal autocorrelation of real physiological recordings.
- CSV files are UTF-8; stage-3 files begin with a byte-order mark.
